6.1 Principios de diseño

Características:

Produce siempre el mismo grafo para el mismo estado de entrada

Para cada change_event:

Se identifica el graph_node afectado

El Graph Engine no clasifica el cambio, solo lo conecta técnicamente.

6.5 Impact Analysis (consultas recursivas)

El impacto se calcula mediante consultas recursivas sobre graph_edge.

Tipos de impacto:

DIRECT: profundidad = 1

INDIRECT: profundidad > 1

Propiedades:

Aguas arriba y aguas abajo

Profundidad configurable

Orden determinístico

Resultados reproducibles

Ejemplo conceptual:

WITH RECURSIVE impact AS (
  SELECT target_node_id, 1 AS depth
  FROM graph_edge
  WHERE source_node_id = :changed_node
  UNION ALL
  SELECT ge.target_node_id, i.depth + 1
  FROM graph_edge ge
  JOIN impact i ON ge.source_node_id = i.target_node_id
)
SELECT * FROM impact;

valida

orquesta

delega

Auditabilidad y trazabilidad

No dependencia de servicios externos críticos
